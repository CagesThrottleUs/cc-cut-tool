# SP-07 Character Mode — 2026-05-29

## What shipped

- `CharProcessor` class: UTF-8 codepoint-aware `-c list` cut mode
- `select_chars(line, list)` — static pure function, independently testable
- `make_processor` now returns `CharProcessor` for `CutMode::CHARACTER`
- 19 new unit tests covering all REQ-001..REQ-006 TCs (190 total)

## Why it matters

Before SP-07, `cc-cut-tool -c 1` printed:
```
cc-cut-tool: character mode not yet implemented
```
After SP-07, `printf 'h\xC3\xA9llo\n' | cc-cut-tool -c 2` correctly outputs `é`.

## Design notes

- `select_chars` tracks `cp_idx` — a counter that increments once per codepoint
  regardless of byte width. Invalid bytes count as 1 codepoint each (ASM-003),
  consistent with ByteProcessor's ASM-002.
- `run()` is structurally identical to `ByteProcessor::run()`.
