# SP-01: Foundation — 2026-05-28

## Summary

Established shared type vocabulary for the cc-cut-tool project. All subsequent
sub-projects depend on these four types.

## New Types

| Type | Header | Description |
|------|--------|-------------|
| `CutMode` | `include/cut/mode.hpp` | Enum distinguishing BYTE / CHARACTER / FIELD mode |
| `CutList` | `include/cut/list.hpp` | Parsed selection list with finite indices and optional open range |
| `CutOptions` | `include/cut/options.hpp` | Aggregated parsed CLI arguments |
| `FileSource` | `include/cut/file_source.hpp` | Abstract interface for line-oriented reading |
