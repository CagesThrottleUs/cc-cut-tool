# SP-05: Field Mode — 2026-05-28

## Summary

The tool is now usable end-to-end for `-f` mode. `main.cpp` is wired to
`parse_args` and `FieldProcessor::run`; the binary processes real files.

## New API

| Symbol | Header | Description |
|--------|--------|-------------|
| `cc_cut::FieldProcessor` | `include/cut/field_processor.hpp` | Processes field mode for a given CutOptions |
| `FieldProcessor::split_fields(line, delim)` | same | Splits line on exact char delimiter |
| `FieldProcessor::split_fields(line)` | same | Splits line on whitespace runs |
| `FieldProcessor::select_fields(fields, list)` | same | Selects fields by CutList |
| `FieldProcessor::process_line(line, out)` | same | Splits, selects, writes one output line |
| `FieldProcessor::run(out, files, err)` | same | Iterates files, returns exit code |

## Behavior Notes

- `-f` mode: field numbers are 1-based in CLI, 0-based internally
- Lines with no delimiter and `-s` not set: passed through unchanged
- Lines with no delimiter and `-s` set: suppressed (not written)
- Missing fields (line has fewer fields than requested): output as empty
- Output delimiter matches input delimiter; `opts.delim.value()` always used

## Not Yet Implemented

- `-b` (byte mode) — SP-06
- `-c` (character mode) — SP-07
