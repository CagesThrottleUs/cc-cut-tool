# SP-03: Arg Parser — 2026-05-28

## Summary

Implemented `cc_cut::parse_args()` — the sequential pipeline that converts
raw `argc`/`argv` into a `ParseResult` ready for the processing pipeline.

## New API

| Symbol | Header | Description |
|--------|--------|-------------|
| `cc_cut::ParseResult` | `include/cut/parse_result.hpp` | Aggregated parse result (opts + files + help_requested) |
| `cc_cut::parse_args` | `include/cut/arg_parser.hpp` | Parse argc/argv → ParseResult |
| `cc_cut::detect_mode` | `include/cut/arg_parser.hpp` | Identify -b/-c/-f mode from first flag |
| `cc_cut::extract_list_spec` | `include/cut/arg_parser.hpp` | Extract list string (attached or separate) |
| `cc_cut::parse_mode_properties` | `include/cut/arg_parser.hpp` | Consume mode-specific flags (-n, -d, -s) |
| `cc_cut::collect_files` | `include/cut/arg_parser.hpp` | Collect file args with first-occurrence dedup |
| `cc_cut::config::program_name` | `include/cut/config.hpp` (generated) | `"cc-cut-tool"` from CMake |
| `cc_cut::config::help_hint` | `include/cut/config.hpp` (generated) | Help hint string |

See `wiki/api/arg_parser.md` (to be created in a future pass) for full reference.

## Error Messages

All errors follow the coreutils format:
```
cc-cut-tool: <message>
Try 'cc-cut-tool --help' for more information.
```

Zero-position errors are translated by mode:
- BYTE/CHARACTER: `"byte/character positions are numbered from 1"`
- FIELD: `"fields are numbered from 1"`

## Design Notes

- Public API keeps `int argc, char** argv` to match POSIX `main()` signature
- `std::span<char*>` used internally to eliminate raw pointer arithmetic
- `--help` is scanned before mode detection so `cut --help` succeeds without a mode flag
