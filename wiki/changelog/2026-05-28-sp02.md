# SP-02: List Parser — 2026-05-28

## Summary

Implemented `cc_cut::parse_list()` — the pure function that converts a
raw `-b`/`-c`/`-f` list argument string into a `CutList` for use by the
processing algorithm.

## New API

| Symbol | Header | Description |
|--------|--------|-------------|
| `cc_cut::parse_list` | `include/cut/list_parser.hpp` | Parse list spec → CutList |

See `wiki/api/parse_list.md` for full reference.

## Namespace Migration

All four SP-01 types (`CutMode`, `CutList`, `CutOptions`, `FileSource`)
retroactively wrapped in `namespace cc_cut {}`. Callers must add
`using cc_cut::X;` declarations or qualify names with `cc_cut::`.

## Build Changes

- `CMAKE_CXX_COMPILER` set to Homebrew LLVM `clang++` in both CMake
  presets so `clang-tidy -p out/build/clang-debug` works correctly
  with C++23 headers (`<expected>`, `<format>`)
- `src/list_parser.cpp` added to `SRC_FILES` (links into both binary
  and test binary)
