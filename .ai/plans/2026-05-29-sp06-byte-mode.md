# SP-06 Byte Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** `.ai/specs/2026-05-29-sp06-byte-mode-design.md`

**Goal:** Implement ByteProcessor for `-b` mode and introduce the Processor strategy pattern (abstract base + make_processor factory), simplifying main.cpp to a single make_processor call.

**Architecture:** ByteProcessor mirrors FieldProcessor in structure (static helpers + process_line + run). A new abstract Processor base and make_processor factory handle all mode dispatch; main.cpp contains no CutMode comparisons. Invalid UTF-8 in `-n` mode is handled via `utf8::internal::validate_next` with a 1-byte fallback per ASM-002.

**Tech Stack:** C++23, GoogleTest, utf8cpp (header-only at `include/utf8.h`), Boost.Iostreams (via existing FileSource layer)

```cpp
auto ByteProcessor::select_bytes(std::string_view line, const CutList& list)
    -> std::string {
  std::string result;
  const auto size = static_cast<int>(line.size());
  const int open_start =
      list.open_from.value_or(std::numeric_limits<int>::max());

    }
  }

}
```

```cpp
auto ByteProcessor::select_bytes_no_split(std::string_view line,
                                          const CutList& list) -> std::string {
  std::string result;
  const int open_start =
      list.open_from.value_or(std::numeric_limits<int>::max());

  // NOLINTNEXTLINE(cppcoreguidelines-pro-type-reinterpret-cast)
  auto it = reinterpret_cast<const utf8::utfchar8_t*>(line.data());
  // NOLINTNEXTLINE(cppcoreguidelines-pro-type-reinterpret-cast)
  const auto end =
      reinterpret_cast<const utf8::utfchar8_t*>(line.data() + line.size());

  while (it != end) {
    const auto* seq_start = it;
    const int start_pos = static_cast<int>(
        // NOLINTNEXTLINE(cppcoreguidelines-pro-type-reinterpret-cast)
        seq_start - reinterpret_cast<const utf8::utfchar8_t*>(line.data()));

    const auto err = utf8::internal::validate_next(it, end);
    if (err != utf8::internal::UTF8_OK) {
      it = seq_start + 1;  // ASM-002: always treat invalid byte as 1-byte char
    }

    if (list.indices.contains(start_pos) || start_pos >= open_start) {
      // NOLINTNEXTLINE(cppcoreguidelines-pro-type-reinterpret-cast)
      result.append(reinterpret_cast<const char*>(seq_start),
                    // NOLINTNEXTLINE(cppcoreguidelines-pro-type-reinterpret-cast)
                    reinterpret_cast<const char*>(it));
    }
  }
  return result;
}
```

> **Note:** `utf8::internal::validate_next(it, end)` is the 2-arg overload from
> `utf8/unchecked.h`. If your build uses a utf8cpp version with only a 3-arg
> overload, change to:
> ```cpp
> utf8::utfchar32_t cp{};
> const auto err = utf8::internal::validate_next(it, end, cp);
> ```

```cpp
auto ByteProcessor::run(std::ostream& out, const std::vector<std::string>& files,
                        std::ostream& err) -> int {
  int exit_code = 0;

  const auto process_source = [&](const std::string& path) {
    auto source_result = make_file_source(path);
    if (!source_result) {
      err << source_result.error() << '\n';
      exit_code = 1;
      return;
    }
    try {
      (*source_result)->load();
    } catch (const std::ios_base::failure& ex) {
      err << config::program_name << ": " << path << ": " << ex.what() << '\n';
      exit_code = 1;
      return;
    }
    while (auto line = (*source_result)->getline()) {
      process_line(*line, out);
    }
  };

  if (files.empty()) {
    process_source("-");
  } else {
    for (const auto& path : files) {
      process_source(path);
    }
  }
  return exit_code;
}
```
